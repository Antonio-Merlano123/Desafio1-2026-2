# Desafio I - Sweet Crush

proyecto de informatica II hecho en c++ con qt widgets.

## primera etapa

en esta etapa se deja creado el archivo de proyecto y se define la organizacion
general que se va a construir poco a poco.

## organizacion planeada

- `bits`: manejo de las fichas usando grupos de 3 bits.
- `tablero`: memoria dinamica y cambios de filas y columnas.
- `juego`: reglas, combinaciones, gravedad y cascadas.
- `interfaz`: ventana y controles de qt.

## compilacion

abrir `Desafio1.pro` con qt creator y seleccionar un kit de qt desktop.
